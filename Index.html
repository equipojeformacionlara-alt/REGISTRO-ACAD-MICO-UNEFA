✎ Cómo editar y agregar docentes

Este archivo HTML es completamente editable. Para modificar los datos, abre el archivo con cualquier editor de texto (Notepad, Notepad++, VS Code, etc.) y busca la sección marcada como DATOS EDITABLES.

Paso 1. Abre el archivo con un editor de texto (clic derecho → Abrir con → Bloc de notas o VS Code).
Paso 2. Presiona Ctrl + F y busca: DATOS EDITABLES
Paso 3. Encontrarás el arreglo const DOCENTES = [...] con todos los docentes.
Paso 4. Cada docente tiene este formato:

{ n:1, nom:'NOMBRE COMPLETO', tipo:'TV', h:7, pend:false }

• n: número de fila
• nom: nombre completo (sin el tipo entre paréntesis)
• tipo: TV, MT, TC o DE
• h: horas asignadas
• pend: true si tiene sección pendiente, false si no
Paso 5. Para agregar un docente, copia una línea existente, pégala al final del arreglo (antes del ]) y actualiza los datos. Recuerda agregar una coma al final de la línea anterior.
Paso 6. Para cambiar las horas máximas por tipo, busca const MAX_HORAS y edita los valores.
Paso 7. Guarda el archivo (Ctrl + S) y recarga en el navegador (F5). ¡Los cambios se reflejan automáticamente!

✅ No necesitas internet para que funcione el dashboard. Solo necesitas el archivo HTML y un navegador (Chrome, Firefox, Edge).
